Aula 11 · Lição 3

Union by rank

No union, a árvore mais baixa vai para baixo da mais alta. Com essa regra, a altura nunca passa de $\log_2 n$, e findSet e union passam a custar $O(\log n)$.

2. O problema

O union da Lição 11.2 sempre põe a raiz de x embaixo da raiz de y. Ele não olha o tamanho das árvores.

Exemplo: juntar estas duas árvores.

A baixa embaixo da alta (pai[5] = 2): altura continua 2.

A alta embaixo da baixa (pai[2] = 5): altura sobe para 3.

Regra

Pendurar uma árvore desce todos os nós dela um nível. Se ela for a mais baixa, a altura total não aumenta.

3. Rank e o código

Definição
  • Cada elemento guarda rank[x].
  • Para uma raiz, rank = altura da sua árvore.
  • O union só compara ranks de raízes.
makeSet(x)
1.  pai[x] = x
2.  rank[x] = 0
union(x, y)
1.  rx = findSet(x)
2.  ry = findSet(y)
3.  if rx = ry then return
4.  if rank[rx] < rank[ry] then
5.      pai[rx] = ry
6.  else if rank[rx] > rank[ry] then
7.      pai[ry] = rx
8.  else
9.      pai[rx] = ry
10.     rank[ry] = rank[ry] + 1
CasoQuem desceRank muda?
rank[rx] < rank[ry]rxnão
rank[rx] > rank[ry]rynão
iguaisrx (convenção do slide)rank[ry] + 1

Por que só o empate muda o rank: se as alturas são diferentes, a mais baixa cabe embaixo da mais alta. Se são iguais (r), os nós mais fundos descem para r + 1.

6. Por que a altura fica ≤ log₂ n

Tente construir a árvore mais alta possível. A altura só sobe num empate, então para chegar à altura h é preciso juntar duas árvores de altura h − 1.

Construindo a árvore mais alta com 8 elementos
Altura h0123⋯h
Nós (no mínimo)1248⋯$2^h$
Na prova, escreva
  1. A altura só aumenta quando se unem duas árvores de mesma altura.
  2. Então cada nova altura exige o dobro de nós: altura h tem pelo menos $2^h$ nós.
  3. Com n nós: $2^h \le n$, logo $h \le \log_2 n$.
