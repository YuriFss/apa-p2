O problema do caixeiro viajante

Um vendedor precisa visitar várias cidades e voltar para casa. Qual a ordem mais barata? Nesta lição: o que é um tour, quantos tours existem e por que testar todos não funciona.

1. O problema, com um exemplo

Usaremos estas 5 cidades em toda a aula. A tabela dá a distância entre cada par. Ela é simétrica: ir de A a B custa o mesmo que ir de B a A.

Cada par de cidades tem uma estrada. O grafo é completo.

Por enquanto, olhe só A, B, C e D. O vendedor sai de A, passa por B, C e D e volta para A:

TrechoA → BB → CC → DD → ATotal
Custo345214

A última coluna é a volta para casa. Sem ela, o custo seria 12, e isso não é um tour.

Caminho A → B → C → D: 3 arestas. Não volta. Não é tour.

Tour A → B → C → D → A: 4 arestas. Fecha o ciclo.

Definição
  • Entrada: n cidades e o custo $c_{ij}$ de ir de i a j.
  • Tour: um ciclo que passa por cada cidade exatamente uma vez e volta à cidade de partida.
  • Custo do tour: a soma das suas n arestas.
  • Objetivo: achar o tour de menor custo.
Compare com a Aula 11

Uma árvore geradora tem $n - 1$ arestas. Um tour tem $n$ arestas: é o caminho mais a volta.

2. Quantos tours existem?

Ainda com 4 cidades. Começamos sempre em A. Sobram B, C e D para ordenar: $3! = 6$ ordens.

#OrdemCustoObservação
1A → B → C → D → A3 + 4 + 5 + 2 = 14
2A → B → D → C → A3 + 7 + 5 + 4 = 19
3A → C → B → D → A4 + 4 + 7 + 2 = 17
4A → C → D → B → A19é a ordem 2 ao contrário
5A → D → B → C → A17é a ordem 3 ao contrário
6A → D → C → B → A14é a ordem 1 ao contrário

Percorrer um ciclo ao contrário usa as mesmas arestas. Então são só 3 tours diferentes:

custo 14 (ótimo)

custo 19

custo 17

Agora para n cidades, em três passos:

  1. Ordens de n cidades: $n!$.
  2. A cidade de partida não importa (o ciclo é o mesmo). Fixe uma: $\dfrac{n!}{n} = (n-1)!$.
  3. O sentido não importa. Divida por 2: $\dfrac{(n-1)!}{2}$.
Regra

Com n cidades (grafo completo e simétrico) existem $\dfrac{(n-1)!}{2}$ tours. Confira: $n = 4$ dá $\frac{3!}{2} = 3$. $n = 5$ dá $\frac{4!}{2} = 12$.

A ideia mais simples: calcular o custo de todos os tours e ficar com o menor. Veja nas 4 cidades:

Funciona. O problema é o tempo. Cada tour custa $O(n)$ para somar, então a força bruta custa $O(n \cdot (n-1)!) = O(n!)$. O slide supõe um computador que testa $10^4$ tours por segundo:

4. O que é resolver "eficientemente"

Exemplo do slide: achar o maior valor de uma lista.

max_val = 0
for j in range(len(l)):
    if l[j] > max_val:
        max_val = l[j]

Uma passada pela lista: $O(n)$. Dobrar a lista dobra o tempo. Isso é eficiente.

Regra (Jack Edmonds, 1965)

Um algoritmo é eficiente quando roda em tempo polinomial: $O(n)$, $O(n^2)$, $O(n^3)$… $O(n!)$ e $O(2^n)$ não são polinomiais.

Para o caixeiro viajante, ninguém conhece um algoritmo exato polinomial. Saber se ele existe é a pergunta P = NP?, ainda aberta. A maioria dos pesquisadores acredita que não existe.

Então, para problemas difíceis, é preciso abrir mão de uma destas três coisas:

Abre mão de…Fica com…Exemplo
garantia de solução ótimatempo polinomial, qualquer instânciaheurísticas: vizinho mais próximo, melhor inserção, 2-opt
tempo polinomialsolução ótima, qualquer instânciamétodos exatos: força bruta, branch-and-bound, programação linear inteira
resolver qualquer instânciaótimo em tempo polinomialalgoritmos para casos especiais

5. Heurística

A palavra vem do grego heurísko, "eu encontro". É a mesma origem de "eureka!".

Definição

Uma heurística é um método rápido (polinomial) que acha uma solução boa, mas sem garantia de que ela seja a ótima.

Cuidado
  • Heurística não "geralmente acha o ótimo global". Às vezes acha, às vezes não. Ninguém garante.
  • As heurísticas desta aula não têm sorteio. Com a mesma entrada, dão sempre a mesma resposta.

Esta aula estuda dois tipos:

TipoO que fazNesta aula
Construtivamonta um tour do zero, uma cidade por vezvizinho mais próximo, melhor inserção
Busca local (melhoria)parte de um tour pronto e faz pequenas trocas que diminuem o custo2-opt, 3-opt

As duas construtivas são gulosas: em cada passo fazem a escolha que parece melhor agora e nunca voltam atrás.
