1. Aquecimento

2. A ideia: cada conjunto é uma árvore

Definição
  • Cada conjunto é uma árvore. Todas juntas formam a floresta.
  • Cada nó guarda só um ponteiro: o seu pai.
  • A raiz aponta para si mesma. Ela é o representante.
  • Vetor pai: o índice é o elemento, o valor é o pai dele.

Os mesmos dois conjuntos, nas duas formas:

Listas ligadas (Lição 11.1): todo nó chega ao conjunto em 1 passo.

Floresta: cada seta vai do filho para o pai. O laço em cima da raiz é pai[r] = r.

Na floresta, achar o representante exige subir até a raiz. Em troca, juntar dois conjuntos muda um único ponteiro.

6. Custo do findSet

Cada chamada sobe um nível. Então:

número de chamadas = profundidade de x + 1

Melhor caso: x é a raiz. 1 chamada: O(1).

Pior caso: a árvore virou uma lista e x está no fundo. n chamadas: O(n).

Na prova, escreva
  1. O find sobe um nível por chamada até a raiz.
  2. Melhor caso O(1): x é a raiz.
  3. Pior caso O(n): todos os n elementos numa árvore em forma de lista, x na ponta.

7. union: três tentativas

O slide tenta três versões. Exemplo para as três: union(1, 4) no vetor da seção 3.

IdeiaCódigoEm union(1, 4)Resultado
1pai[x] = ypai[1] = 4Errado: 5, 0 e 6 ficam de fora.
2pai[findSet(x)] = ypai[5] = 4Certo, mas a altura vai para 5.
3pai[findSet(x)] = findSet(y)pai[5] = 3Certo, altura 3. É a versão do slide.
union(1, 4) nas três versões

Laranja: caminho do findSet. Verde: o ponteiro que mudou. Vermelho: nós que ficaram de fora.

Por que a ideia 1 falha: só a seta de x muda. Os nós acima de x (0 e 5) e os outros ramos (6) não apontam para x, então ficam na árvore antiga.

union(x, y)
1.  pai[findSet(x)] = findSet(y)
Regra

Ligue raiz com raiz. O custo vem dos dois findSet: O(n) no pior caso.

8. O problema da altura

Pior casoListas ligadasFloresta
makeSet$O(1)$$O(1)$
findSet$O(1)$$O(n)$
union$O(n)$$O(n)$

A floresta só perde por causa da altura. Exemplo: union(0,1), union(1,2), …, union(6,7) forma uma lista.

Altura 7: findSet(0) faz 8 chamadas.

Mesmos 8 elementos, altura 2: no máximo 3 chamadas.
